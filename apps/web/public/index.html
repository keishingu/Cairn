# リリース準備 にメッセージ送信Message #release-prep
01

コメントが、チャットになるComments become chat

案件のスレッドが、リアルタイムの会話として進む。投稿して終わり、ではない。The project thread moves like realtime chat. Posting is not the end of the conversation.

02

話したことが、仕事として残るWhat you said stays as the work

決めたこと、共有したファイル、チェックした作業。会話の流れは消えない。Decisions, files, and checklists stay on the project. The thread does not wash away.

03

人数では、料金は増えないPrice is not per seat

会話のメンバーは無制限。お金がかかるのは、大きなファイルと、自分から使う AI だけ。Unlimited members for conversation. You pay for large uploads and for AI you initiate.

FAQ

よくある質問

Questions people search

Backlog のコメントと Chatwork や Slack を、Cairn にまとめられますか？ Can Cairn replace a mix of project comments and work chat?

案件のコメント欄が、リアルタイムのチャットとして進みます。Backlog の課題コメントと Chatwork や Slack を行き来しているチームが、その置き場所として使っています。各製品の全機能を置き換える比較ではありません。会話の人数では課金しません。 Project comments work like realtime chat, so you don’t keep a tracker thread and a chat app in parallel. Teams coming from Backlog comments plus Chatwork or Slack use Cairn as that one place. This is not a feature-by-feature replacement. Chat is not priced per seat.

Notion や LINE に残した連絡も、移せますか？ What about notes in Notion or chats in LINE?

ドキュメントや個人チャットに残っていた連絡を、案件の会話として残せます。Cairn は Notion や LINE そのものではありません。コメントがチャットになり、話したことが仕事として残ることが中心です。 You can keep that conversation on the project instead of in a doc or a personal chat. Cairn is not Notion or LINE. The core is comments becoming chat, and what you said staying as the work.

# App Store screenshots

App Store Connectへ提出する日本語スクリーンショットをここで管理する。

## 仕様

- iPhone 6.9インチ用の縦画像を1〜10枚用意する
- 推奨キャプチャサイズ: 1320 × 2868 px（iPhone 16 Pro Max）
- PNGまたはJPEG
- デモ用ワークスペースを使い、実在する利用者・顧客・秘密情報を表示しない
- ステータスバー時刻、表示言語、テーマを全画像で揃える
- 画像内に未提供機能や誤解を招く表現を追加しない

## 推奨構成

1. `01-projects.png` — プロジェクト一覧と全体像
2. `02-chat.png` — リアルタイムチャットとメンション
3. `03-tasks.png` — タスク、担当者、期限
4. `04-calendar.png` — プロジェクトカレンダー
5. `05-files.png` — ファイルまたはギャラリー

実機相当の本番ビルドをTestFlightへ配信し、デモ用審査アカウントでログインして撮影する。スクリーンショットはApp Store Connectへ手動でアップロードする。

# Google Play ストア掲載情報（日本語）

Play Console の「ストアの設定 → メインのストアの掲載情報」へ手で貼り付ける文面。EAS Metadata は App Store 専用のため、`store.config.json` とは別に管理する。文言を変えるときは `store.config.json` の App Store 側と内容を揃える。

## アプリ名（30文字以内）

```
Cairn
```

## 簡単な説明（80文字以内）

```
チームのプロジェクト管理・チャット・タスク・カレンダー・ファイル共有をひとつに
```

## 詳しい説明（4000文字以内）

```
Cairnは、小さなチームのプロジェクト管理、チャット、タスク、カレンダー、ファイル共有をひとつにまとめるコラボレーションアプリです。

主な機能
・ワークスペースとプロジェクトの管理
・リアルタイムチャットとメンション通知
・タスク、担当者、期限の管理
・プロジェクトカレンダー
・ファイルと画像の共有
・複数端末での同期

チームの会話と仕事の進捗を分断せず、必要な情報へすばやくアクセスできます。

ご利用にはアカウントの作成（メールアドレス、または Google アカウント）が必要です。アカウントはアプリ内の設定 → アカウント → アカウントを削除、または Web 版の同じ画面からいつでも削除できます。
```

## 画像素材

| 素材                              | 仕様                                                              | 置き場所                                               |
| --------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------ |
| アプリアイコン                    | 512 × 512 PNG（32bit）、1MB 以下                                  | `apps/mobile/assets/icon.png` をそのまま使う           |
| フィーチャー グラフィック         | 1024 × 500 PNG / JPEG。**必須**。文字は少なく、端 10% は余白      | `store/screenshots/play/feature-graphic.png`（ロゴ + タグライン。Play Console へアップロード済み） |
| スマートフォン スクリーンショット | 2〜8枚、9:16、短辺 320px 以上・長辺 3840px 以下。1080 × 2400 推奨 | `store/screenshots/play/phone/`（未作成）              |
| 7インチ / 10インチ タブレット     | タブレット対応として掲載する場合に各 1枚以上                      | 当面は対象外（下記）                                   |

スクリーンショットの撮影方針（デモ用ワークスペース、同一テーマ・言語・時刻、未提供機能を描かない）と推奨構成は [`screenshots/README.md`](./screenshots/README.md) と同じ。Android は Pixel 相当のエミュレータまたは実機で、内部テスト版の本番ビルドから撮る。

タブレットは `app.json` で `android.screenOrientation` などを制限していないためインストール自体は可能だが、レイアウト確認が済むまで Play Console の「タブレット向け」の掲載素材は登録しない。

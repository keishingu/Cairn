# Cairn

## 開発者向けセットアップ

### 必要な環境

- Node.js 20+
- pnpm 9+

### セットアップ

```bash
pnpm install
```

### 主なコマンド

```bash
pnpm dev        # 開発サーバー起動 (apps/web)
pnpm build      # 全パッケージビルド
pnpm typecheck  # 型チェック
pnpm lint       # Lint
pnpm test       # テスト
pnpm format     # コードフォーマット
```

### DBマイグレーション

```bash
cd packages/db
pnpm db:generate  # スキーマからマイグレーションファイル生成
pnpm db:push      # DBに直接反映 (開発用)
pnpm db:studio    # Drizzle Studio 起動
```

### 環境変数

`.env.example` をコピーして `.env.local` を作成し、各値を設定する。

```bash
cp .env.example apps/web/.env.local
```

### リポジトリ構成

```
cairn/
  apps/
    web/                # Next.js 15 (メインWebアプリ)
  packages/
    core/               # ドメイン / ユースケース / ポート定義
    db/                 # Drizzle ORM スキーマ・クライアント
    shared/             # 共有型・Zodスキーマ
    config/             # tsconfig・ESLint共有設定
```

## 1. 概要

山岳部の山行計画を起点とした、プロジェクト管理・チャット・カレンダー・ファイル管理・ギャラリー・AIアシスタントを統合したコラボレーションアプリケーション。

将来的には山岳部だけでなく、イベント運営、採用管理、研究活動、施工管理、地方企業の業務推進などへ横展開可能な汎用プロダクトを目指す。

---

## 2. コンセプト

### 1つのイベント = 1つのプロジェクト

各プロジェクトに以下を一元管理する。

- 日程
- ステータス
- チャット
- ファイル
- タスク
- メンバー
- ギャラリー
- AIアシスタント

---

## 3. コア価値

既存ツールを置き換えるのではなく、Slack / Teams、Google Calendar / Outlook、Excel / PDF / PowerPoint などの既存業務ツールを活かしながら、プロジェクト推進を滑らかにする。

## 7. ギャラリー機能

山行後・イベント後に撮影した写真を共有するための機能。

### 主な機能

- 写真アップロード
- 動画アップロード
- 一括アップロード
- サムネイル表示
- フルスクリーン表示
- キャプション
- 撮影日時
- 撮影者
- コメント
- いいね
- ダウンロード
- タグ付け
- アルバム管理

---

## 8. AI機能

AIは固定機能として実装しない。

AGENTS.md 的なMarkdownプロンプトにより、各組織・各業務に合わせてAIの振る舞いを定義する。

### AIの役割

- ファイル参照
- チャット履歴参照
- プロジェクト情報参照
- メンバー情報参照
- HTMLテンプレート出力
- チャット欄でのHTMLレンダリング

---

## 9. 差別化

### Backlogとの差別化

- コメント中心ではなくチャット中心
- ギャラリー機能
- AGENTS.mdによるAIカスタマイズ
- Slack / Teams連携
- Google Calendar / Outlook連携
- FDE的導入支援

### Notionとの差別化

- 自由すぎない
- ワークフローを持つ
- チャット中心
- 既存ツール連携
- 業務構造化に特化

# UIデザイン作成依頼プロンプト

添付する参考画像（PC版・スマホ版のモックアップ）をベースに、以下の要件を満たすWebアプリケーションのUIデザインを作成してください。

---

## プロジェクト概要

山岳部の山行計画を起点とした、プロジェクト管理 + チャット + カレンダー + ファイル管理 + ギャラリー + AIアシスタントを統合したコラボレーションアプリケーションです。

将来的には山岳部だけでなく、イベント運営、採用管理、研究活動、施工管理などへ横展開可能な汎用プロダクトを目指しています。

---

## コンセプト

### 1つのイベント = 1つのプロジェクト

各プロジェクトごとに以下を一元管理します。

- 日程
- ステータス
- チャット
- ファイル
- タスク
- メンバー
- ギャラリー
- AIアシスタント

## デザインの方向性

### 必須要件

- ダークテーマとライトテーマの両方を作成してください
- 同じレイアウトでテーマのみ切り替え可能な設計
- デザインシステムとして一貫性のあるカラー・コンポーネント設計

### トーン

- モダン
- ミニマル
- プロフェッショナル
- 余白を活かしたデザイン
- SaaSらしいクリーンなUI

### 雰囲気

- modern B2B SaaS
- Linear
- Notion
- Slack
- Vercel

## デザインで重視したいこと

1. 情報量が多くても見やすい
2. チャット中心で操作しやすい
3. 山岳部用途でも一般業務でも違和感がない
4. モダンなSaaSデザイン
5. ダーク/ライト両テーマで美しい
6. デスクトップとスマホで一貫したUX
7. ギャラリーが魅力的
8. AI機能が自然に組み込まれている

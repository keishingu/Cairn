# ファイル

- ファイル一覧は `/files`。**プロジェクト別にグループ表示**され、どのプロジェクトにも属さないファイルは「プロジェクトなし」セクションにまとめられる
- ファイルの実体はチャットへの添付から作られる（「チャットでファイルを送ると、ここに表示されます」）
- **ファイル名の変更**: ファイル一覧の各行右側の「…」メニューを開き、「名前を変更」（編集アイコン）を選ぶ。ファイル名がその場でインライン編集可能になり、Enterで確定・Escでキャンセル
- 保存フィルター（名前を付けて保存する絞り込み条件）は**ユーザー×ワークスペース単位**で保存され、他のユーザーや他のワークスペースとは共有されない

# プロジェクト

- プロジェクト一覧は `/projects`。表示ビューは「一覧」「カレンダー」「カンバン」の3種類を切り替えられる
- ビューの選択はURLパラメータではなく **localStorage** に保存される（PC用とモバイル用で別々のキー）。ブラウザ・端末を変えると選択は引き継がれない
- プロジェクト詳細は `/projects?open=project-{プロジェクトID}`（`project-` プレフィックス必須。`useDetailPanel()` がこの形式でしかパネルを認識しない）で、一覧の上にパネル表示される（旧 `/projects/[id]` は自動でこの形式にリダイレクトされる）

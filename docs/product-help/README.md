# プロダクトヘルプ文書（`/ai` ナレッジ用）

`/ai`（調査ワークベンチ）が「マイルストーンの使い方」「ファイル名の編集はどこから」といった **Cairnというプロダクト自体の使い方**に関する質問に答えられるよう、機能別の解説を Markdown で保持するディレクトリ。

## 位置づけ

`/ai` は元々ワークスペース内データ（プロジェクト・タスク・ファイル・メッセージ）を調査する用途で設計されており（[`docs/10_ai_member_design.md`](../10_ai_member_design.md) §2）、RAG対象の `document_chunks` はワークスペースごとに閉じたデータで権限フィルタが前提になっている。プロダクトの使い方説明は全ワークスペース共通・非機密の情報のため、性質が異なる別経路として持たせる。

## 実装方式

現状は**静的注入方式**（ワークスペースRAGとは別）を採用している。

- 本ディレクトリの内容は `apps/web/src/lib/ai/product-help.ts` に文字列として保持し、`/ai` の system prompt に常時含める
- DB・embedding は使わない。ここに書いたMarkdownは資料であり、実際にモデルへ渡る本文は `product-help.ts` 側が正
- 文書量が増えて全文注入のコストが無視できなくなったら、ワークスペース非依存の専用RAGテーブル（`document_chunks` とは別）+ 専用toolへの移行を検討する（`packages/db/src/schema/embeddings.ts` の `document_chunks` はワークスペース単位のアクセス制御が前提のため流用しない）

## 更新ルール

機能の追加・変更・UI導線の変更をした場合は、該当するこのディレクトリの文書と `apps/web/src/lib/ai/product-help.ts` の両方を更新する（CLAUDE.mdの「開発手順・アーキテクチャに変更があった場合はドキュメントを更新する」と同じ運用）。

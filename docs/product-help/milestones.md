# マイルストーン

- プロジェクトの節目（例: 初回リリース）を、期間つきで登録できる機能
- 「マイルストーンを作成」から、プロジェクト詳細（概要タブ）やチャット画面などから作成できる
- 入力項目: マイルストーン名（必須・100文字以内）、説明（任意・1000文字以内）、開始日・終了日・開始時刻・終了時刻（すべて任意）
- **新規作成すると、そのマイルストーン専用のチャットチャンネルが自動で作成される**
- 作成済みのマイルストーンは同じフォームから編集でき、既存の入力値が引き継がれる
- マイルストーンの作成・編集には member 以上のロールが必要（guest は作成・編集不可。`POST /api/projects/[id]/milestones` がAPI側でも拒否する）
- カレンダービューで期間が可視化され、プロジェクト一覧・詳細からも参照できる

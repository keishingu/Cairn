# チャット

- チャンネルには3種類ある: プロジェクトチャンネル（`project`）、ワークスペース全体のチャンネル（`workspace`）、DM（`dm`）
- プロジェクトに紐づかないチャンネルと、その直下のスレッドは、チャット一覧のメニューから名称変更と削除ができる。チャンネルの変更・削除は管理者以上、スレッドはメンバー以上。削除するとメッセージとタスクも消え、チャンネルを削除すると配下のスレッドも消える。プロジェクトチャンネルと DM は対象外
- DMは `FEATURE_FLAGS.dm` で制御され、現在は本番を含む全環境で利用できる（CLAUDE.md参照）
- マイルストーンを作成すると、そのマイルストーン専用のチャットチャンネルが自動で作られる（[マイルストーン](./milestones.md) 参照）
- チャンネルにファイルを送ると、そのファイルは自動でファイル一覧（`/files`）に反映される
- Markdown のコードブロックを `mermaid` として記述すると図として表示される。同じ記法を含む `.md` ファイルもプレビューで図を表示できる
- プロジェクトチャンネルとワークスペースチャンネルでは、チェックボックス（`- [ ]`）付きの発言がタスク一覧へ自動反映される。DMは対象外
- ワークスペースチャンネルの詳細欄から、そのチャンネルに紐づくタスクを追加できる。非公開チャンネルのタスクは参加メンバーにだけ表示される
- チャット・通知・未読はリアルタイムに同期される（画面を開いたまま他のメンバーの操作が反映される）

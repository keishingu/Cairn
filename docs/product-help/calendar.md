# カレンダービュー

- プロジェクト一覧（`/projects`）の表示ビューの1つ。月表示でマイルストーンやプロジェクトの予定を確認できる
- 週の始まりは設定 → 外観で日曜または月曜を選べる。未設定時は日曜始まり。選択は本人のプロフィールに保存され、端末をまたいで同じ並びになる
- 月表示では、スマホは上スワイプで次の月・下スワイプで前の月、PCは下方向のホイールで次の月・上方向のホイールで前の月に移る。週表示の時間スクロールとタイムラインの一覧スクロールはそのまま
- マイルストーンは期間（開始日〜終了日）に応じて日付にまたがって表示される
- 日付やマイルストーンをクリックすると詳細（マイルストーン編集や該当プロジェクトへの遷移）を開ける

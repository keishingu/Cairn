# モバイルチャット同等性・オフライン送信チェックリスト

**ステータス: 主要導線を実機相当のiOSシミュレータで検証済み**

**更新日: 2026-07-23**

**比較対象:** iPhoneの実UAで表示したモバイルWeb ／ Expo Development Buildのネイティブチャット

## 完了条件

山中など通信が不安定で操作時間も短い状況を最優先し、次を完了条件とする。

1. チャット本文・返信を圏外で送っても端末内から失われない。
2. 通信復帰後はユーザーが再操作しなくても自動送信される。
3. 応答受信前に回線が切れて再送しても、同じメッセージが二重投稿されない。
4. モバイルWebで日常的に使うチャット操作へ、ネイティブ画面から到達できる。

## オフライン送信

| 項目 | 実装 | 状態 |
|---|---|---|
| 端末内への永続化 | 初回POSTより前に、ユーザー別AsyncStorageキューへ本文・返信先・送信先・作成時刻・アップロード済みfile IDを保存 | [x] |
| 待機状態の表示 | スレッド内に「電波待ち・接続後に自動送信」を表示。手動再試行と取消も可能 | [x] |
| 自動再送 | 8秒間隔とアプリ前面復帰時に再送。通信障害時は後続を止めて送信順を維持 | [x] |
| アプリ再起動 | `sending` を `waiting` として復元し、同じクライアントIDで再送 | [x] |
| 二重投稿防止 | クライアント生成UUIDを `messages.id` に使用。サーバーは同じ送信者・チャンネルの既存行を成功として返す | [x] |
| 保存競合防止 | enqueue・再送・再試行・取消を直列化し、常に最新キューから更新。端末保存成功後にだけ待機中として表示 | [x] |
| 送信直後の画面移動 | 別チャンネルへ移動していても、送信時のチャンネルIDでキューへ保存 | [x] |
| 添付 | 通信中にアップロード完了済みの添付は本文と一緒にキューへ保存 | [x] |
| 完全オフラインの新規添付 | 端末ローカルファイルそのものの永続化・後送は未対応 | [ ] |

添付のアップロードは署名URL発行・Storage転送・DB確定の3段階が必要なため、今回の最優先範囲は本文と返信の確実な送信とした。完全オフラインで選んだ画像・ファイルの後送は次段階とする。

# モバイルチャット表示の同等性チェックリスト

**ステータス: 検証済み**  
**更新日: 2026-07-12**  
**比較対象:** モバイルUAの `localhost:3128/chats` と `localhost:3128/chats/{channelId}` ／ Expo ネイティブのチャット一覧・スレッド

## 目的と判断基準

Expo はチャットだけをネイティブ実装にしているため、WebViewで表示する他画面と連続して見えることを優先する。機能の全コピーではなく、まず「同じデータが同じ階層と視覚的な意味で読める」状態を完了条件にする。

| 項目 | モバイルWebの基準 | ネイティブでの対応 | 状態 |
|---|---|---|---|
| 一覧ヘッダー | 白いヘッダー、チャット見出し | 同じカード背景・見出し・アクセントアイコン | [x] |
| チャンネル一覧 | `プロジェクト` / `チャンネル` / `ダイレクトメッセージ` / `アプリ` の見出し、罫線の行、未読バッジ、遷移矢印 | 全セクションを同じ順序で表示。親チャンネルと未完了マイルストーンを同じ階層で表示 | [x] |
| チャンネル名 | 親はプロジェクト名、マイルストーンはチャンネル名 | 親遷移時はプロジェクト名をスレッド見出しへ渡す | [x] |
| スレッドヘッダー | 戻る操作・チャンネル名・白背景 | 一覧に固定して戻る緑の操作・チャンネル名を表示 | [x] |
| 通常メッセージ | アバター、送信者、日時、本文のフラットな行 | 吹き出し表示を廃止し、同じ情報の行へ変更 | [x] |
| システムメッセージ | 中央寄せの控えめなピル | `messageType: system` を利用して同じ表現に変更 | [x] |
| 添付 | ファイル種別アイコン付きのチップ | MIME種別に応じたアイコンとファイル名チップを表示 | [x] |
| 返信・編集済み・リアクション | 返信プレビュー、編集済み表示、リアクションチップ | API DTOを保持して表示。既存リアクションはタップで切替可能 | [x] |
| 入力欄 | 下部固定の角丸コンポーザー、送信アイコン | 同じ配色・プレースホルダー・送信状態を表示 | [x] |
| 既読 | 開いているスレッドの最新取得後に既読化 | 既存の先読み防止ロジックを維持 | [x] |

## 意図的に別実装として残すもの

- ネイティブ側の添付アップロード、画像プレビュー、メンション候補、絵文字追加、返信の新規作成、ブックマーク・編集・削除、チャンネル作成、DM開始は未実装。Webの操作ボタンを見た目だけで追加せず、実行できない操作を示唆しない。
- Markdown はプレーンテキストとして表示する。メンションは既存の解決済み表示名に変換する。
- WebはRealtime Broadcast、Expoは現行の5秒ポーリングを使用する。今回の範囲は表示同等性であり、購読方式は変更しない。

## 設計原則

1. **原価がかかる場所（ストレージ・AI）で課金し、テキスト＋小さいファイルは無料**
2. **AIは純従量課金にしない** — メーター不安がAIメンバーの利用を抑制し、ハートビート（AIの自発行動）と従量課金は構造的に相性が悪い。定額内クレジット + 前払いクレジットパック + BYOK で構成する
3. **課金者は個人でも、恩恵はワークスペースに帰属させる** — 支払者の卒業・退会でワークスペースが機能を失わないように。重ね掛け可能な「支援」モデルにする
4. **チャット履歴は無料プランでも無制限** — テキストの原価はほぼゼロ。履歴制限による課金誘導はしない
5. **ゲスト招待は全プラン無料・無制限** — 社外コラボレーションの普及導線なので課金設計で制限しない
6. **OSS版に機能ペイウォールを作らない** — Cloud で課金するのは「ホストされた資源（容量・AIクレジット・バックアップ）と運用の手間」であって機能ではない

### セルフホスト版との関係

**セルフホストは Expedition 相当の機能を自前のインフラで利用できる。** 機能制限・ペイウォールは設けない（設計原則 6）。

- ストレージは自前、AI は BYOK（自分の API キー）で無条件利用可
- SSO / 監査ログ等の法人向け機能も、実装され次第 OSS に含める
- サポートはコミュニティベース。商用サポート・FDE 導入支援が必要な場合は別契約（Expedition と同じ窓口）

### ロールアウト順序

- **初期は Free + Stone のみ**で開始する
- Party は団体・法人の引き合いが出てから追加
- Expedition の収益の本体はプラン料金ではなく **FDE 導入支援と年間サポート契約**。プラン表はその入口。クラウド（Expedition）かセルフホスト支援かの判断も FDE が伴走して行う

## 命名の意図

| 名前 | 意図 |
|---|---|
| **Free** | 最もライトなユーザー層が触れるため、固有名を付けず馴染みのある名称にする |
| **Stone（積み石）** | ケルンは通る人が石を積んで道標になる。個人が団体を支える行為＝「石を積む」。課金ボタンは「石を積む / Stack a stone」。重ね掛けはケルンに石が積み上がるビジュアルで可視化する。**あとの人のために積む文化**により、支払者の卒業が「継承の儀式」になる（卒業時に「◯◯先輩が積んだ石」が残る・OB積み石） |
| **Party** | 山岳用語の「パーティ」= チーム。Club より山の文脈が出る |
| **Expedition** | 遠征隊 = 資金・装備・組織が揃った本格山行。法人の隠喩。個人の登山 → パーティ → 遠征隊という規模の物語が一本通る |

不採用・回避した候補と理由（再検討の無駄を省くため記録）: Trail（無料プランに固有名は不要）、Alpine（Alpine Linux / Alpine.js を連想）、Trailhead（Salesforce の学習サービス名）、Climb（汎用的すぎる）、Belay（登山者以外に通じない）、Sherpa（民族名の商用流用は批判の前例があり使用しない）、歩荷（国際展開で通じない）

## AIクレジット設計の方針

- 各プランに定額で内包。超過は**前払い・使い切りのクレジットパック**（青天井の従量メーターは置かない）
- 無料枠は「味見」：メンション応答（AIメンバー Stage 1）を月数十回。マジックモーメントは無料で体験できるようにする
- **AIメンバーの常駐（Stage 2-3: 承認付きアクション・ハートビート）が有料の目玉**。「AI機能の解放」ではなく「AI部員の入部」として訴求する
- ハートビートの一次判定は gpt-4o-mini で原価を抑える（[`10_ai_member_design.md`](./10_ai_member_design.md) 参照）
- BYOK: セルフホストは無条件。Cloud では Party 以上を想定（開放範囲は未決事項）

## 決済の実務

- **購入導線は当面 Web のみ**（Stripe 想定）。アプリ内課金（IAP）は実装コストと手数料のため初期は見送り
- アプリ内では Web 決済ページへのリンクアウトで誘導する。日本ではスマホソフトウェア競争促進法（2025年末全面施行）により、リンクアウト誘導が規約リスクなしで成立しやすい
- 将来 IAP を導入する場合、アプリ経由価格は **¥450**（手数料 30% 控除後の手取り約 ¥315 ≒ Web の ¥300。二重価格の定石）
- ¥300 の薄利対策として、年払い（¥3,000/年 など）や複数口まとめ買いの導線で決済手数料率を改善する
- Party の価格は、国産プロジェクト管理 SaaS のエントリープラン相場（月額 3,000 円前後）と同価格帯に置く

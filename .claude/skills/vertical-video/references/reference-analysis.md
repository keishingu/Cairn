# 参考動画の解析ガイド

`scripts/analyze_reference.sh <URL> <outdir>` の出力を読み、構造分解をまとめる。

## スクリプトの出力

```
<outdir>/
  source.mp4        # 動画本体（yt-dlp が取得できた形式）
  info.json         # yt-dlp メタデータ（タイトル・説明・尺・解像度・再生数・投稿者 等）
  *.vtt             # 自動字幕（取得できた場合。ja/en）
  frames/f001.jpg…  # 1fps のサンプルフレーム（幅360px。Read ツールで画像として読める）
```

## 読み方

1. **info.json**: `duration`（尺）, `width/height`（縦型か）, `view_count`/`like_count`（勝ちパターンとしての信頼度）, `title`/`description`（訴求コピーの型）
2. **frames/**: 連番で数枚ずつ Read し、カット割りの位置・テキストオーバーレイの様式（フォントの太さ・配置・背景帯の有無）・実写/画面収録/モーショングラフィックスの別を観察する
3. **字幕(.vtt)**: ナレーション・セリフの構成。フックの一文、問題提起→解決の流れ、CTA の文言

## 構造分解のフォーマット（ユーザー提示用）

```markdown
## 参考動画の構造分解
- 尺 / 形式: 22秒 / 画面収録 + テキストオーバーレイ
- フック (0-1.5s): 「まだ◯◯してるの？」型の問題提起。画面中央に大きな白抜きテキスト
- 展開 (1.5-15s): 3つの機能を各4秒でテンポよく。カットごとにズームイン
- 転換点: 8s 付近でビフォー→アフターの対比
- CTA (15-22s): プロフィールリンク誘導。ロゴ + 一言
- テキスト様式: 太ゴシック白抜き+黒縁、画面上1/3、1カット1メッセージ
- テンポ: 平均カット長 2.8s、BGM のビートに同期
- なぜ見られるか（仮説）: 冒頭の損失回避フック + 短いカットで離脱ポイントを作らない
```

## 解析できないときの扱い

- **Instagram**: 未ログインでは yt-dlp が失敗することが多い。エラーをそのまま伝え、①動画ファイルの直接提供 ②同等の TikTok/YouTube Shorts URL の提供 をユーザーに依頼する
- **ネットワークポリシーによる遮断**: リモート実行環境では外部ドメインへのアクセスが遮断されることがある。エラー内容を提示し、ローカル実行またはファイル提供を案内する
- いずれの場合も**サイレントに一般論へフォールバックしない**（CLAUDE.md のエラー表示方針に従う）

ユーザーが動画ファイルを直接提供した場合は、`analyze_reference.sh` の代わりにファイルへ直接 ffmpeg を実行してフレーム抽出する:

```bash
FF="${FFMPEG_PATH:-$(command -v ffmpeg || python3 -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')}"
"$FF" -i source.mp4 -vf "fps=1,scale=360:-2" frames/f%03d.jpg
```
